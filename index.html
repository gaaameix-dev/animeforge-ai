The pipeline

Twelve stages, run to whatever depth the brief needs.

A

Brief

Title, logline, genre, tone, audience, platform, runtime, language, aspect ratio.

B

Story

Premise, stakes, conflict, escalation, ending — or the episode hook.

C

Script

Scene headings, action, dialogue with speakers, approximate timings.

D

Characters

Character bibles with identity anchors so faces and outfits survive every shot.

E

World

Locations, architecture, lighting, color script, continuity rules.

F

Storyboard

Size, angle, movement, action, duration, prompt, negative prompt — per shot.

G

Animation

Blocking, timing, spacing, anticipation, effects; 2D cels or 3D rigs.

H

Audio

Voice profiles, dialogue script, ambience, SFX cues, music brief, mix notes.

I

Production

Uses only tools that actually exist, tracks job ids, verifies outputs.

J

Edit

Edit decision list, titles, subtitles, grade, export settings.

K

QA

Continuity, pacing, lip-sync, rights, aspect ratio — as a severity list.

L

Code frames

Frames drawn in code — construction, cel shading, line, light rig, lens and motion that read as hand-drawn.

Drawn in code, not just planned

When the frames are built by writing code — SVG, Canvas, CSS, WebGL — the skill becomes the illustrator, and holds itself to drawing rules: one light rig for the whole film, construction before styling, cooler saturated shadows, tinted line weight, real lens numbers, acting on twos, seeded and deterministic output, and a verification list that ends with a squint test and a 12/24fps flip test.

Honest about what it is

A skill, not a renderer. It plans and directs; it does not generate video, images or voices by itself. With a generation tool connected it uses it and verifies the output. Without one, it hands you production-ready prompts, shot lists, audio plans and assembly instructions — and says plainly that nothing has been rendered.
