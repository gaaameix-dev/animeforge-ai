# AnimeForge AI — Production Checklist

## Brief
- [ ] Confirm concept, runtime, language, aspect ratio, and platform.
- [ ] Confirm 2D, 3D, or hybrid visual direction.
- [ ] Confirm whether this is a short, trailer, episode, or film.

## Pre-production
- [ ] Create story bible and screenplay.
- [ ] Create character bibles and identity anchors.
- [ ] Define locations, art direction, and color script.
- [ ] Break the script into timed shots.
- [ ] Prepare image/video prompts and negative prompts.
- [ ] Prepare voice, music, ambience, and SFX plans.

## Production
- [ ] Confirm connected tools and actual capabilities.
- [ ] Obtain approval before paid generation when required.
- [ ] Reuse reference assets for character consistency.
- [ ] Generate shots separately when practical.
- [ ] Track task IDs and verify completion.

## Post-production
- [ ] Check character, prop, and environment continuity.
- [ ] Check shot order, pacing, screen direction, and transitions.
- [ ] Check dialogue, lip-sync, music, and sound balance.
- [ ] Check subtitles, aspect ratio, and export settings.
- [ ] Share only verified files and links.
